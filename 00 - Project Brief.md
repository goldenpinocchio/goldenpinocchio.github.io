# GoldenPinocchio — Homepage Project Brief

## Project Goal

Create a playful, colorful, personality-driven homepage for **GoldenPinocchio** that acts as a visual gateway to my projects.

The homepage should immediately feel inviting and interesting. It should encourage visitors to explore by making each project feel distinct, clickable, and worth opening.

This should **not** feel like a traditional corporate portfolio, résumé site, or generic developer homepage.

The experience should feel more like entering a small creative world built around the projects.

---

## Primary Inspiration

Reference:

**Jennifer Xiao**  
[https://www.jenniferxiao.com/](https://www.jenniferxiao.com/)

The goal is **not to copy the site**, but to borrow qualities such as:

- playful composition
    
- strong personality
    
- colorful visual language
    
- hand-made or illustrated feeling
    
- unconventional layout
    
- curiosity-driven navigation
    
- projects presented as objects worth interacting with
    

---

## Desired Personality

The homepage should feel:

- playful
    
- colorful
    
- creative
    
- slightly whimsical
    
- friendly
    
- personal
    
- visually memorable
    
- project-focused
    
- experimental without becoming confusing
    

It can have some imperfection and character.

Avoid making everything feel overly polished, sterile, symmetrical, or corporate.

---

## Core Experience

A visitor should be able to land on the homepage and quickly understand:

1. This is **GoldenPinocchio**
    
2. This person makes interesting things
    
3. These are the projects
    
4. I can click around and explore them
    

The projects should be the primary attraction.

The homepage should invite exploration rather than requiring visitors to read a lot of explanatory text.

---

## Homepage Structure

### 1. Identity / Intro

Include a lightweight introduction near the top of the page.

Possible elements:

- **GoldenPinocchio**
    
- short greeting
    
- short tagline
    
- small piece of playful supporting copy
    

Keep this concise.

The intro should establish personality without taking attention away from the projects.

---

### 2. Project Playground

The main area of the homepage should display current projects as interactive visual entries.

These could appear as:

- illustrated cards
    
- stickers
    
- floating objects
    
- mini windows
    
- posters
    
- buttons
    
- tiles
    
- icons
    
- small scenes
    
- other playful visual elements
    

The project elements do **not** all need to look identical.

Allow each project to have some of its own personality while still belonging to the same overall visual system.

Each project should clearly communicate:

- project name
    
- enough visual or textual context to make someone curious
    
- that it is clickable
    

Where appropriate, external project sites should open in a new tab.

---

## Interaction Direction

Interactions should feel satisfying but lightweight.

Possible examples:

- slight movement on hover
    
- scale or rotation
    
- illustrated reactions
    
- changing borders or shadows
    
- playful cursor interactions
    
- small animations
    
- subtle floating elements
    

Do not overload the page with constant motion.

Animations should support the playful character of the site rather than distract from navigation.

---

## Visual Direction

For v1, aim for a blend of:

**playful editorial + digital scrapbook + light retro influence**

The site can use:

- bold colors
    
- contrasting typography
    
- irregular positioning
    
- outlined elements
    
- textures
    
- doodles
    
- stickers
    
- simple illustrations
    
- unexpected spacing
    
- layered objects
    

Avoid committing the entire site to a heavy arcade aesthetic unless individual projects call for it.

GoldenPinocchio should feel broader than one specific theme.

---

## Layout Principles

The layout should feel intentional but not rigid.

Prefer:

- asymmetry
    
- visual variety
    
- breathing room
    
- clear clickable targets
    
- strong visual hierarchy
    
- responsive composition
    

Avoid:

- generic three-column portfolio grids
    
- identical SaaS-style cards
    
- excessive navigation
    
- dense text sections
    
- complicated dashboard-style UI
    

Mobile should remain easy to navigate even if the desktop version uses a more free-form composition.

---

## V1 Scope

Build only what is needed for a strong first homepage.

### Include

- homepage
    
- GoldenPinocchio identity
    
- short intro/tagline area
    
- project links
    
- playful project presentation
    
- responsive desktop/mobile layout
    
- hover/interactivity where appropriate
    

### Optional

- small About / Info button
    
- simple footer
    
- social or GitHub links
    

### Do Not Build Yet

- full About page
    
- blog
    
- CMS
    
- complex project filtering
    
- user accounts
    
- heavy animation system
    
- elaborate navigation architecture
    

Keep the architecture easy to extend later.

---

## Technical Direction

The implementation should remain:

- lightweight
    
- responsive
    
- fast-loading
    
- easy to edit
    
- easy to add new projects to
    
- maintainable by AI coding agents
    

Project information should preferably live in a simple reusable data structure rather than being duplicated throughout the page.

For example, each project could eventually contain:

- name
    
- URL
    
- description
    
- image/icon
    
- color/theme
    
- status
    
- external/internal link behavior
    

The page should render project entries from that data wherever practical.

---

## External Links

For project links that lead away from the GoldenPinocchio site:

- open them in a new tab
    
- use appropriate `target="_blank"` and security attributes
    
- make it visually clear that the project is clickable
    

Internal GoldenPinocchio pages should remain in the same tab.

---

## Creative Guardrail

Do not solve the homepage by defaulting to a conventional portfolio template.

Before adding additional sections, ask:

**Does this make the site more fun to explore, or is it simply adding more website?**

Prioritize personality, projects, and interaction over feature count.

---

## Definition of Success

The first version is successful when:

- the homepage immediately feels like GoldenPinocchio has a personality
    
- the projects dominate the experience
    
- visitors naturally want to click something
    
- the site works well on desktop and mobile
    
- adding another project later is simple
    
- the page feels creative without becoming difficult to use
    
- the implementation remains lightweight enough to iterate quickly
    

---

## Current Open Questions

These should remain unresolved until the project list, inspiration audit, and homepage plan are reviewed:

- Which projects should receive the most visual prominence?
    
- Should projects use a loose free-form layout or a more structured composition?
    
- How illustrated versus text-driven should the page become?
    
- What exact tagline should appear beneath GoldenPinocchio?
    
- Should an About / General Info entry appear in v1?
    
- Should different projects receive their own visual styles?
    
- How much animation should be used?
    
- Which project links are internal versus external?
