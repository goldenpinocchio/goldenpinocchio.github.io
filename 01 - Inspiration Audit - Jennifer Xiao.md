# Inspiration Audit — Jennifer Xiao

## Reference

**Jennifer Xiao**  
[https://www.jenniferxiao.com/](https://www.jenniferxiao.com/)

---

## Why This Site Is Relevant

Jennifer Xiao’s homepage is a useful reference because it avoids the conventions of a traditional portfolio.

Instead of leading with a résumé-style introduction, services list, case-study grid, or long biography, the homepage acts as a **visual launchpad** into different parts of her creative world.

The primary lesson is not the exact layout or artwork.

The lesson is:

**Navigation itself can become part of the personality of the site.**

The clickable objects are both interface and illustration.

That is the core idea worth carrying into GoldenPinocchio.

---

## Homepage Behavior

The homepage behaves more like a playful interactive directory than a standard portfolio.

Visitors are presented with a small number of visually distinctive destinations and are encouraged to explore them.

The experience is built around:

- immediate visual personality
    
- recognizable clickable objects
    
- minimal explanatory copy
    
- clear destinations
    
- generous spacing
    
- curiosity-driven interaction
    

The homepage does not attempt to explain everything at once.

It gives visitors a reason to click.

---

## Observed Structure

The homepage uses a relatively small number of large visual navigation elements.

Examples of destinations include:

- Illustration
    
- About
    
- Comics
    
- Merchandise
    
- Instagram
    
- Shop
    

These destinations are represented primarily through illustrated or image-based buttons rather than conventional navigation cards.

Internal pages and external destinations coexist naturally within the same visual system.

This makes the homepage feel less like a menu and more like a collection of portals.

---

## Navigation Pattern

The central interaction model is:

**visual object → click → destination**

The object itself communicates that something can be explored.

This is important because the imagery is not merely decorative.

It performs a functional role in the interface.

For GoldenPinocchio, project artwork, icons, cards, stickers, screenshots, or illustrated objects should ideally serve the same dual purpose:

1. create visual personality
    
2. provide navigation
    

---

## What Makes the Experience Work

### 1. Small Number of Choices

The page does not overwhelm the visitor with dozens of links.

A limited number of large destinations makes each one feel important.

For GoldenPinocchio, the strongest projects should receive clear visual priority instead of giving every project identical weight.

---

### 2. Visual Navigation

The homepage does not rely on a conventional navigation bar as the primary experience.

The visual objects themselves guide the visitor.

This creates a stronger sense of discovery.

GoldenPinocchio should explore this same idea with project-specific visual portals.

---

### 3. Generous Negative Space

The elements have room around them.

The page does not feel like a dense dashboard or marketplace grid.

This gives the individual objects more personality and makes the composition feel deliberate.

---

### 4. Strong Individuality

The website feels unmistakably tied to the creator.

It does not resemble a generic portfolio template.

The typography, illustrations, composition, and navigation all contribute to that identity.

GoldenPinocchio should aim for the same result:

**someone should be able to see the homepage and recognize that it belongs to this project ecosystem specifically.**

---

### 5. Minimal Copy

The site allows visual design to carry much of the communication.

There is not excessive descriptive text competing with the artwork.

For GoldenPinocchio, project descriptions should generally be short.

A project name, visual identity, and perhaps one small supporting line should often be enough.

---

## Visual Qualities Worth Borrowing

GoldenPinocchio should borrow the following principles:

- bright, expressive color
    
- playful illustration
    
- irregular but intentional composition
    
- visual objects as navigation
    
- large clickable areas
    
- generous spacing
    
- friendly tone
    
- simple information hierarchy
    
- a sense of entering a creative world
    
- project discovery through curiosity rather than heavy explanation
    

---

## What Not to Copy Literally

The goal is not to reproduce Jennifer Xiao’s homepage.

Avoid directly copying:

- individual illustrations
    
- exact page composition
    
- button shapes
    
- typography
    
- artwork placement
    
- color combinations
    
- specific navigation graphics
    

GoldenPinocchio should develop its own visual language.

The reference is useful primarily as a **design philosophy**.

---

## GoldenPinocchio Translation

The most useful adaptation is to treat each project as its own small visual object or portal.

For example, a project could appear as:

- an arcade cabinet
    
- a sticker
    
- a game cartridge
    
- a miniature browser window
    
- a notebook
    
- a sign
    
- a toy
    
- a poster
    
- a character
    
- a floating icon
    
- a small illustrated scene
    

The visual treatment can reflect the personality of the project while still sharing a broader GoldenPinocchio design system.

This creates variety without turning the homepage into an unrelated collection of styles.

---

## Suggested Interaction Model

A visitor lands on the homepage and sees a handful of distinctive project objects.

Hovering or tapping may trigger lightweight responses such as:

- small movement
    
- tilt
    
- scale
    
- shadow change
    
- animation
    
- short label reveal
    
- cursor reaction
    
- subtle sound only if intentionally added later
    

Clicking the object opens the project.

External projects can open in a new tab.

Internal GoldenPinocchio content should remain within the same site.

---

## Homepage Composition Lesson

Do not automatically default to:

- a hero banner
    
- followed by a three-column card grid
    
- followed by an About section
    
- followed by a contact section
    
- followed by a large footer
    

Instead, allow the project objects to become the composition.

The homepage itself can function almost like a small illustrated desk, wall, playroom, scrapbook, arcade, or creative workspace.

The exact metaphor can be developed later.

---

## Practical Takeaways

For GoldenPinocchio:

- use the homepage primarily as a project launchpad
    
- keep the initial number of visible destinations relatively small
    
- give stronger projects more visual prominence
    
- turn project visuals into functional navigation
    
- keep explanatory copy short
    
- allow generous spacing
    
- prioritize personality over portfolio convention
    
- let projects have different visual treatments
    
- maintain enough consistency that the page still feels like one world
    
- make adding future projects straightforward
    
- reserve deeper biography and information for secondary pages or interactions
    

---

## Technical Observation

The reference site appears to use relatively simple image-driven navigation.

The important takeaway is that the effect does **not** require a complicated application architecture.

GoldenPinocchio should achieve the same sense of personality with a lightweight implementation.

The project data and visual components should remain modular so the site can grow without requiring a redesign.

---

## Core Design Principle

The strongest idea to carry forward from this reference is:

**Do not make visitors browse a portfolio. Make them want to explore a world.**

For GoldenPinocchio, every major project entry should feel like something worth touching, opening, or discovering.
